Partie I · Algèbre linéaire / 线性代数Linear algebra線形代数

正交矩阵Orthogonal matrices

列向量两两垂直且长度为一；这类变换只旋转、不拉伸，所以长度与角度都不变。

Columns are mutually perpendicular and unit length; such maps only rotate, so lengths and angles survive.

QᵀQ = I ⟹ det(Q) = ±1

行列式 det(A)Determinant det(A)

衡量线性变换对「体积」的缩放倍数；|det| 是倍数，符号表示是否翻转方向。

How much a linear map scales volume; |det| is the factor and the sign says whether orientation flips.

det = a(ei−fh) − b(di−fg) + c(dh−eg)

易错：det = 0 说明矩阵不可逆，变换把平面压成一条线。

Pitfall: det = 0 means the matrix is not invertible — the plane collapses onto a line.

矩阵乘法 = 复合变换Matrix product = composition

先做 B 再做 A，合起来就是 A·B；次序不能交换。

Apply B first, then A — that is A·B, and the order matters.

(AB)[i][j] = Σ_k A[i][k]·B[k][j]

易错：A·B ≠ B·A；只有单位矩阵与所有矩阵可交换。

Pitfall: A·B ≠ B·A; only the identity commutes with everything.

秩与可解性Rank and solvability

秩 = 线性无关的列数 = 变换后空间的维数。

Rank = number of independent columns = dimension of the image.

rank(A) = n ⟺ Ax = b 唯一解

易错：方程个数多不等于有解，要看增广矩阵的秩。

Pitfall: more equations does not mean solvable — compare ranks of A and [A|b].

特征值 / 特征向量Eigenvalues and eigenvectors

特征向量是「变换后方向不变」的方向，特征值是它被拉伸的倍数。

An eigenvector keeps its direction under the map; its eigenvalue is the stretch factor.

Av = λv ⟺ (A − λI)v = 0

易错：λ = 0 是合法特征值，意味着该方向被压成零。

Pitfall: λ = 0 is legitimate — that direction is crushed to zero.

正交与投影Orthogonality and projection

点积为零即垂直；投影是找「某方向上最接近」的点。

Zero dot product means perpendicular; projection finds the closest point along a direction.

proj_a(b) = (a·b / a·a)·a

易错：分母是 a·a，别写成 |a| 漏掉平方。

Pitfall: the denominator is a·a, not |a|.

最小二乘Least squares

方程无解时，退而求残差平方和最小的解。

When a system has no solution, minimise the sum of squared residuals instead.

AᵀA x̂ = Aᵀb

易错：只要求 AᵀA 可逆（列满秩），不要求 A 可逆。

Pitfall: we need AᵀA invertible (full column rank), not A itself.

奇异值分解 SVDSingular value decomposition

任意矩阵都能拆成「旋转—拉伸—旋转」；奇异值就是各方向被拉伸的倍数，按从大到小排列。

Every matrix factors into rotate–stretch–rotate; singular values are the stretch factors, ordered largest first.

A = UΣVᵀ

易错：SVD 对任意矩阵都存在，不要求方阵，也不要求可对角化。

Pitfall: SVD exists for every matrix — square and diagonalisable are not required.

正定矩阵Positive definite matrices

对称矩阵对任意非零向量都给出正二次型；等价于所有特征值为正。

A symmetric matrix with xᵀAx > 0 for every nonzero x; equivalently all eigenvalues are positive.

xᵀAx > 0 (x ≠ 0) ⟺ λᵢ > 0

易错：只看对角线为正不够，必须检查整个矩阵。

Pitfall: a positive diagonal is not enough; check the whole matrix.

零空间与秩-零化度Null space and rank–nullity

零空间是被映射成零的向量集合；秩-零化度定理把秩与零空间维数加起来等于列数。

The null space collects vectors mapped to zero; rank–nullity says rank plus nullity equals the number of columns.

rank(A) + nullity(A) = n

易错：零空间只含零向量时，列向量线性无关。

Pitfall: if the null space is only the zero vector, the columns are independent.

Partie II · Analyse / 微积分Calculus微積分

单调性与极值Monotonicity and extrema

导数正负决定升降：由正变负是极大值，由负变正是极小值；导数为零只是候选点。

The sign of f′ decides slope: positive→negative is a maximum, negative→positive a minimum. f′=0 alone is only a candidate.

f′(x)=0 且 f″(x)<0 ⟹ 极大值

导数 = 瞬时变化率Derivative = instantaneous rate

某点切线的斜率；也等于「输入动一点点，输出变多少」的极限。

The slope of the tangent, i.e. the limit of output change per tiny input change.

f′(x) = lim(h→0) [f(x+h) − f(x)] / h

易错：可导必连续，连续不一定可导（如 |x| 在 0 处）。

Pitfall: differentiable implies continuous, not the reverse (|x| at 0).

链式法则Chain rule

复合函数求导 = 外层导数 × 内层导数。

Differentiating a composition multiplies outer and inner derivatives.

(f∘g)′(x) = f′(g(x))·g′(x)

易错：忘记乘内层导数，是最常见的丢分点。

Pitfall: forgetting the inner derivative is the classic mistake.

定积分 = 累积量Definite integral = accumulation

曲线下的有向面积；切细、求和、取极限。

Signed area under a curve: chop, sum, take the limit.

∫ₐᵇ f = lim(n→∞) Σ f(xᵢ)·Δx

易错：x 轴下方的面积为负，有向面积不等于几何面积。

Pitfall: below the axis the contribution is negative; signed area ≠ geometric area.

微积分基本定理Fundamental theorem

求导与积分互为逆运算，这是能算起来的原因。

Differentiation and integration invert each other, which is what makes computation possible.

d/dx ∫ₐˣ f(t)dt = f(x)

易错：上限是 x 的函数时要再乘链式法则的导数。

Pitfall: with a variable upper limit you must multiply by the chain-rule factor.

泰勒展开Taylor expansion

用多项式在一点附近逼近函数，阶数越高越贴合。

Approximate a function locally with polynomials; higher order hugs it longer.

f(x) ≈ Σ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ

易错：展开只在 a 附近有效，离得越远误差越大。

Pitfall: the expansion is local — error grows as you move away from a.

梯度 = 最速上升方向Gradient = steepest ascent

梯度指向函数增长最快的方向，模长是那个方向的变化率。

The gradient points uphill; its length is the rate of change in that direction.

∇f = (∂f/∂x, ∂f/∂y, …)

易错：梯度是向量不是数；下降要沿 −∇f 走。

Pitfall: the gradient is a vector; descend along −∇f.

多变量链式法则Multivariable chain rule

沿一条路径对时间求导，要把每个中间变量的偏导相乘，再把各条路径的贡献相加。

Differentiating along a path multiplies each intermediate partial and sums the contributions from every branch.

d/dt f(x(t), y(t)) = f_x·x′ + f_y·y′

易错：别漏掉路径本身的导数 x′(t)、y′(t)。

Pitfall: do not drop the path derivatives x′(t) and y′(t).

拉格朗日乘子Lagrange multipliers

在约束 g = 0 上找极值，目标函数的梯度必须与约束梯度平行；乘子 λ 是约束的“影子价格”。

At a constrained extremum the objective gradient is parallel to the constraint gradient; λ is the shadow price of the constraint.

∇f = λ∇g,  g(x) = 0

易错：先检查约束边界与梯度为零的退化点。

Pitfall: check constraint boundaries and degenerate points where gradients vanish.

泰勒余项Taylor remainder

截断到 n 阶后剩下的误差，可以用下一阶导数在某个中间点的值来控制。

The error after truncating at order n is controlled by the next derivative at some intermediate point.

Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (x−a)ⁿ⁺¹

易错：余项给的是范围，不是精确误差；ξ 通常未知。

Pitfall: the remainder bounds the error; ξ is usually unknown.

Partie III · Langage C / C 语言The C languageC 言語

const 与指针的位置Where const sits

const 修饰的是它右边的东西：`const char *` 是「指向常量的指针」，`char * const` 才是「指针本身不可改」。

const binds to what is on its right: `const char *` points to constant data, while `char * const` is a constant pointer.

const char *p;   /* 数据只读 */
char * const q;  /* 指针只读 */

数组与指针Arrays and pointers

数组名在表达式里会退化成指向首元素的指针，但数组本身不是指针：sizeof 与赋值行为都不一样。

An array name decays to a pointer in expressions, but it is not a pointer: sizeof and assignment behave differently.

a[i] ≡ *(a + i)

栈与堆Stack and heap

局部变量在栈上、函数返回即失效；malloc 的内存由你负责 free，返回局部数组的地址是典型错误。

Locals live on the stack and die with the call; malloc'd memory is yours to free. Returning the address of a local array is the classic bug.

int *p = malloc(n * sizeof *p);

字符串以 '\0' 结尾Strings end with '\0'

C 的字符串就是字节数组加一个终止符，长度要自己数；漏掉终止符会让 strlen 越界。

A C string is a byte array plus a terminator; you track the length yourself, and a missing terminator sends strlen off the end.

char s[6] = "hello";  /* 5 + '\0' */

结构体与内存布局Structs and layout

字段之间可能有填充字节，所以 sizeof(结构体) 常常大于各字段之和；比较要用 memcmp 之外的方式。

Padding can sit between fields, so sizeof a struct often exceeds the sum of its members — never compare two structs byte by byte.

struct Rec { int id; double score; };

函数指针Function pointers

函数名在表达式里会退化成指向函数的指针；可以用它做回调、分派表和 qsort 的比较函数。

A function name decays to a pointer in expressions; use it for callbacks, dispatch tables and qsort comparators.

int (*cmp)(const void *, const void *);

易错：声明时括号不能省，`int *cmp(...)` 是返回指针的函数。

Pitfall: keep the parentheses; int *cmp(...) is a function returning a pointer.

位运算Bit operations

与、或、异或、移位直接操作二进制位；x & (x−1) 可以清掉最低位的 1。

AND, OR, XOR and shifts operate on bits directly; x & (x−1) clears the lowest set bit.

x & (x - 1)  /* clear lowest set bit */

易错：有符号负数的右移是实现定义行为，优先用无符号类型。

Pitfall: right-shifting a negative signed value is implementation-defined; prefer unsigned types.

未定义行为Undefined behaviour

越界、解引用空指针、有符号溢出、读取未初始化变量都属于未定义行为；编译器可以做任何事。

Out-of-bounds access, null dereference, signed overflow and uninitialised reads are undefined behaviour; the compiler may do anything.

int a[3]; a[3] = 0;  /* UB */

易错：“本机能跑”不代表合法，开 -fsanitize=address,undefined 检查。

Pitfall: “it runs here” is not legality — use -fsanitize=address,undefined.

Partie IV · Python / PythonPythonPython

推导式与生成式Comprehensions and genexps

方括号立刻造出整个列表，圆括号是惰性生成器；条件写在后面做过滤，比 for + append 更短也常更快。

Square brackets build the whole list at once; parentheses give a lazy generator. A trailing if filters, and it is shorter (often faster) than for + append.

[x*x for x in a if x % 2]

异常处理的三段式try / except / else / finally

try 放可能出错的语句，except 只捕获明确列出的异常类型；else 在没有异常时执行，finally 无论如何都执行。

try holds the risky call, except names the exact exception types to catch, else runs when nothing failed, and finally always runs.

except (ValueError, ZeroDivisionError) as e:

可变与不可变Mutable vs immutable

int、str、tuple 不可变，list、dict、set 可变；「变量」绑定的是对象，赋值只是换绑。

int, str and tuple are immutable; list, dict and set are not. A name binds to an object, and assignment only rebinds it.

a = [1]; b = a; b.append(2)  # a 也变了

四种容器怎么选Choosing a container

按顺序访问用 list，按键查找用 dict，去重与集合运算用 set，固定记录用 tuple。

list for order, dict for lookup by key, set for uniqueness and set algebra, tuple for a fixed record.

d.get(key, default)  # 不抛 KeyError

默认参数只求值一次Default arguments evaluate once

def f(x, acc=[]) 里的空列表在定义时就创建了，多次调用会共享同一个——要用 None 当哨兵。

The [] in def f(x, acc=[]) is created once at definition time and shared across calls — use None as the sentinel.

def f(x, acc=None): acc = acc or []

生成器与惰性求值Generators and laziness

yield 让函数变成迭代器，一次只产出一个值，适合大文件与无限序列；它只能遍历一次。

yield turns a function into a one-pass iterator producing values on demand — ideal for big files and infinite sequences.

def nat(): n = 0
    while True: yield n; n += 1

装饰器Decorators

装饰器是接收函数并返回新函数的高阶函数；@wraps 会保留原函数的名称与文档。

A decorator takes a function and returns a new one; @wraps preserves the original name and docstring.

from functools import wraps
@wraps(f)
def wrapper(*a, **kw): ...

易错：忘记 functools.wraps 会让日志和调试信息失真。

Pitfall: forgetting functools.wraps distorts logs and debugging.

上下文管理器Context managers

with 保证进入时准备、退出时清理；实现 __enter__/__exit__，或用 contextlib.contextmanager。

with guarantees setup on entry and cleanup on exit; implement __enter__/__exit__ or use contextlib.contextmanager.

with open(path) as f:
    data = f.read()

易错：清理逻辑要放在 finally/__exit__ 里，别只写在正常路径。

Pitfall: cleanup must live in finally/__exit__, not only on the happy path.

dataclassDataclasses

@dataclass 自动生成 __init__、__repr__ 和比较方法；frozen=True 可以做成不可变值对象。

@dataclass generates __init__, __repr__ and comparisons; frozen=True makes an immutable value object.

@dataclass(frozen=True)
class P: x: int; y: int

易错：可变默认值要用 field(default_factory=...)，不能直接写 []。

Pitfall: use field(default_factory=...) for mutable defaults, never a bare [].

Partie V · Probabilités / 概率统计Probability & statistics確率統計

条件概率与贝叶斯Conditional probability and Bayes

条件概率把样本空间缩到已知事件内；贝叶斯公式把先验与似然合成后验。

Conditional probability restricts the sample space to a known event; Bayes combines prior and likelihood into a posterior.

P(A|B) = P(B|A)·P(A) / P(B)

易错：分母 P(B) 是全概率，不是 P(B|A)。

Pitfall: the denominator P(B) is the total probability, not P(B|A).

期望与方差Expectation and variance

期望是加权平均；方差是偏离期望的平方的平均。标准差是方差的平方根。

Expectation is a weighted mean; variance is the mean squared deviation. Standard deviation is its square root.

Var(X) = E[X²] − (E[X])²

易错：E[X²] ≠ (E[X])²，除非 X 几乎必然为常数。

Pitfall: E[X²] ≠ (E[X])² unless X is almost surely constant.

大数定律与中心极限定理LLN and the central limit theorem

大数定律说样本均值收敛到期望；中心极限定理说标准化后的均值近似正态，和原始分布形状无关。

The law of large numbers says the sample mean converges to the expectation; the CLT says the standardised mean is approximately normal regardless of the original shape.

(X̄ − μ) / (σ/√n) → N(0, 1)

易错：CLT 是近似；样本小或重尾时要谨慎。

Pitfall: the CLT is an approximation — be careful with small samples or heavy tails.

最大似然估计Maximum likelihood

选让观测数据出现概率最大的参数；通常对对数似然求导并令其为零。

Choose the parameter that makes the observed data most likely; usually differentiate the log-likelihood and set it to zero.

θ̂ = argmaxθ Σ log p(xᵢ|θ)

易错：似然不是概率；比较不同模型时要考虑参数个数。

Pitfall: likelihood is not probability; account for parameter count when comparing models.

假设检验与 p 值Hypothesis testing and p-values

p 值是在原假设下出现当前或更极端结果的概率；它不是原假设为真的概率。

A p-value is the probability of the observed or more extreme result under the null; it is not the probability that the null is true.

p = P(T ≥ t_obs | H₀)

易错：p 小只说明数据与原假设不合，不等于效应大。

Pitfall: a small p only says the data disagree with the null; it does not mean a large effect.
